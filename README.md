🎯 Jogo da Forca

Jogo da forca em português do Brasil, feito com HTML, Tailwind CSS e JavaScript puro, em um único arquivo. Mais de 1.800 palavras, cada uma com categoria e dica, todas sem acentuação para facilitar a jogabilidade.

▶️ [Jogar agora](https://jonasdamaia.github.io/jogo_forca/)

✨ Funcionalidades
* +1.800 palavras distribuídas em dezenas de categorias (Frutas, Animais, Profissões, Geografia, Tecnologia, Esportes, Sentimentos e muito mais)
* Dica para cada palavra, exibida junto com a categoria
* Palavras sem acento: basta acertar as letras de A a Z, sem se preocupar com til, cedilha ou circunflexo
* Sem repetição na mesma sessão: a lista é embaralhada e só recomeça depois que todas as palavras saem
* Placar de vitórias e erros durante a sessão
* 6 tentativas com boneco desenhado em SVG, que aparece parte por parte com animação
* Teclado virtual na tela e suporte ao teclado físico
* Efeitos sonoros gerados pela Web Audio API (sem arquivos de áudio), com opção de ligar e desligar
* Layout responsivo, pensado para celular e desktop, com tema escuro
* A palavra sempre cabe em uma única linha: o tamanho das letras se ajusta ao comprimento


🕹️ Como jogar
1. Leia a categoria e a dica no painel à esquerda.
2. Escolha letras no teclado da tela ou no teclado do computador.
3. Cada letra errada desenha uma parte do boneco. Você tem 6 tentativas.
4. Descubra a palavra antes de completar o boneco para vencer.
5. Clique em Nova Palavra para começar outra rodada.
   
🚀 Executando localmente

Não há dependências nem etapa de build.
