Jogo da Forca Brasileiro

Um jogo da forca moderno, interativo e responsivo, desenvolvido com foco em palavras e expressões da cultura, culinária, fauna, folclore e cotidiano do Brasil (estritamente sem acentuação).

🚀 Demonstração das Funcionalidades

Cultura Brasileira: Banco de palavras rica em referências nacionais (como BRIGADEIRO, CARNAVAL, CURUPIRA, MANDIOCA, etc.), acompanhadas de dicas úteis.

Palavras sem Acentuação: Padronizado para aceitar e exibir apenas letras maiúsculas de A a Z sem diacríticos.

Gerenciamento Inteligente: As palavras são sorteadas de forma a nunca se repetirem até que todo o banco de dados da sessão seja esgotado.

Design Responsivo & Linha Única: O container de letras calcula o tamanho dinamicamente para garantir que a palavra inteira caiba perfeitamente em uma única linha, seja em celulares, tablets ou computadores.

Efeitos Sonoros (Web Audio API): Sons sintetizados nativamente para cliques, acertos, erros, vitória e derrota (sem arquivos de áudio externos pesados).

Interface Moderna (Glassmorphism): Estilizado com Tailwind CSS, gradientes suaves, animações SVG em etapas para a forca e painel de placar em tempo real.

🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando o conceito de arquivo único (Single-File Component) para facilitar o deploy e o compartilhamento:

HTML5 Semantic

Tailwind CSS (via CDN)

Vanilla JavaScript (ES6+)

Web Audio API (para efeitos sonoros programáticos)

Google Fonts (Fredoka e Inter)

🕹️ Como Jogar

Acesse o jogo publicado via GitHub Pages (ou abra o arquivo index.html em qualquer navegador moderno).

Leia a dica e a categoria fornecidas no painel esquerdo.

Clique nas letras do teclado virtual ou digite diretamente usando o teclado físico do seu computador.

Tente adivinhar todas as letras antes que o boneco da forca seja completamente desenhado (você tem até 6 erros permitidos).

Clique em "Nova Palavra" para continuar jogando e acumular vitórias!
